# Hashington – Testversionen

**Neueste Testversion:** https://github.com/cmedia87-pixel/download/releases/latest

Windows: die ZIP-Datei laden, entpacken und `HostileTakeweed.exe` starten. Die Anleitung steht in `LIESMICH.md` in der ZIP.

## Fehler melden

1. Im Spiel **F12** drücken (oder **Esc → Fehler melden**), kurz aufschreiben, was passiert ist, und **Bericht speichern** klicken.
2. Hier einen Fehlerbericht anlegen und die Datei `bugreport-….zip` hineinziehen:
   **https://github.com/cmedia87-pixel/download/issues/new?template=fehlerbericht.yml**

Dafür brauchst du ein kostenloses GitHub-Konto. Alles hier ist öffentlich sichtbar: Der Bericht enthält Spielstand, Bildschirmfoto, Versionsnummer, Angaben zu Windows und Grafikkarte und das Spiel-Log, aber nichts, was du nicht selbst hineinschreibst.
